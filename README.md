# Smart-Campus-Energy-Consumption-Analysis
Power BI dashboard project analyzing campus electricity consumption patterns.
## Project Overview
This project focuses on analyzing electricity consumption patters across different buildings in a smart campus environment using Microsoft Power BI.
The goal of the project is to visualize energy usage trends, identify high-consumption areas, and provide insights that can help improve energy efficiency within the campus.
By transforming raw electricity usage data into interactive dashboards, the project demonstates how business intelligence tools can support data-driven decision-making.
----
## Objectives
- Analyze electricity consumption across multiple campus buildings.
- Identify buildings with the highest energy usage.
- Track monthly electricity usage trends.
- Visualize energy distribution using different charts.
- Provide insights that help improve energy management.
----
## Tools and Technologies Used
- Microsoft Power BI - Data visualization and dashboard creation
- Microsoft Excel - Dataset preparation and organization
- Github - Project documentation and repository hosting
----
  ## Data Information
  - The dataset used in this project conatins electricity consumption data for multiple campus buildings across different months.
 Dataset columns include:
- Building
- Month
- Electricity_usage_kWh
The dataset was created for educational purposes to demonstrate energy analysis using Power BI.
----
  ## Dashboard Visualizations
  - Bar Chart - Electricity usage by building
  - Pie Chart - Energy distribution across buildings
  - Line Chart - Monthly electricity usage trend
  - Stacked Column Chart- Monthly usage comparision between buildings
  - Area Chart - Overall electricity consumption trend
  - KPI Card - Total campus electricity usage
----
  ## key insights
  - Classroom blocks consume the highest electricity due to continuous academic activities.
  - Libraries and laboratories also show high ennergy usage because of computers and lab equipment.
  - Administrative buildings consume comparatively less electricity.
  - Electricity usage varies across monts depending on campus activity and seasonal conditions.
----
  ## Results
   The analysis shows that total electricity consumption across campus buildings is approximately 70,000 kWh.
   Visual dashboards help quickly identify high energy consumption areas and monthly trends.
